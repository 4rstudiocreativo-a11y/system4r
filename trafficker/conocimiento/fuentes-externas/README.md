# Fuentes externas (cursos, mentores, investigaciones)

Aquí se guarda el conocimiento de terceros: notas de cursos que hayas comprado (Felipe Vergara, u otros media buyers), transcripciones de clases, hilos, artículos de Meta, casos de estudio.

## Por qué esta carpeta existe
El agente **no se "entrena"** como un modelo nuevo: lee estos archivos cada vez que trabaja. Eso es una ventaja — puedes agregar, corregir o borrar conocimiento en cualquier momento y el cambio aplica en la siguiente sesión.

Lo que el agente ya trae (metodología en `../01` a `../05`) son principios públicos y ampliamente aceptados del media buying actual: consolidación, segmentación amplia, creativo como segmentación, fase de aprendizaje, escalado gradual. No contiene material privado de ningún curso. Si tienes acceso a un curso, **tú** traes las notas aquí.

## Cómo agregar una fuente
Crea un archivo `apellido-tema.md` (ej. `vergara-embudos-whatsapp.md`) con este formato:

```markdown
# Fuente: <autor> — <curso/clase/artículo>
Fecha: AAAA-MM
Tipo: curso pagado | video público | artículo | experiencia propia

## Tácticas concretas
- Táctica 1: qué hacer exactamente, con números si los da.
- ...

## Contexto / supuestos
(¿Para qué presupuesto, país, nicho aplica?)

## ¿Lo probamos? 
- [ ] Pendiente — experimento propuesto: ...
```

## Regla de oro
Una táctica de un curso es una **hipótesis** hasta que funcione en nuestras cuentas. El agente propondrá probarla como experimento (`../../bitacora/experimentos.md`) y solo pasará a la metodología si gana con datos.

Respeta los derechos de autor: guarda tus notas y resúmenes, no subas videos ni PDFs completos de cursos pagados a un repositorio público.
